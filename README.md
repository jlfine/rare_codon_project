# Scripts for rare codon patch project
This repository contains the relevant code for the major analyses in our manuscript:

Rare codon patches coordinate an RNA regulatory network and are impacted by repeat expansions linked to brain disorders

Fine et al. (2026)

## Overview
We perform an integrative multi-omics analysis of rare codon patches in human protein-coding genes.

## Code

`get_sequences.ipynb` - identify rare codon patches and construct background controls  
`run_analyses.ipynb` - compare rare codon patches to backgrounds for functional genomics readouts     
`run_genes_omics.ipynb` - compare RCPGs to background genes for functional analyses   
`hmm` - directory for hidden Markov model analysis
`human_genetics.ipynb` - population genetics analysis   
`evolution_simulation.py` - conservation of rare codon patches across Zoonomia
